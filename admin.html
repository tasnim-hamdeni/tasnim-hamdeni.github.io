How do I create a token?
  1. Sign in to the GitHub account with write access to the lesson-data repository.
  2. Open GitHub’s fine-grained token settings ↗. Give the token a name and a short expiration.
  3. Choose the repository’s resource owner. Under Only select repositories, choose .
  4. Grant repository Contents: Read and write. GitHub also includes Metadata: Read-only. Leave other permissions unset.
  5. Generate the token, paste it above, and connect. Keep it secret and revoke it in GitHub if exposed.

The browser cannot enforce a token’s scope. Choose the single repository when creating it. This static admin page has no separate password login.
